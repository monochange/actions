# Add the publish-draft-releases action variant

Publishes the draft GitHub releases for a release, including every target whose `release` flag is true in the matching `.monochange/releases/*/release.json` record. The action retries HTTP 5xx, rate limiting, and network errors with exponential backoff, fails at once on 4xx, reads every release back to confirm it is public, and marks only the primary tag as latest.
