# Load action metadata after removing GitHub expressions from descriptions

GitHub evaluates `${{ }}` in action metadata, so the literal `${{ toJSON(needs) }}` in the root and `ci` `needs` input descriptions failed with `Unrecognized named-value: needs` and stopped the action from loading. Both descriptions now name `toJSON(needs)` as plain text, and a test rejects any `${{` in an action metadata description.
